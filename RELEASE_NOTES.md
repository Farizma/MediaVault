## Media Vault 1.0.0

The first release: a Windows media library and player for your own movie and TV folders.

**Install:** download `MediaVault_v1.0.0_setup.exe` below and run it. The setup wizard lets you choose the folder:
your own user folder needs no administrator rights; Program Files (or "Install for all users") asks Windows for permission.
On first start Media Vault downloads its video engine (libmpv, or libVLC on low-power PCs) with a progress window.

**Windows SmartScreen:** this build is not code-signed yet, so Windows may say it "protected your PC".
Choose *More info* › *Run anyway*. The SHA-256 of the setup file is listed below so you can check the download.

### Highlights
- Library tabs per folder, search, sort and filters, Grid or Spine Shelf view, box sets (TMDB collections or your own)
- 3D DVD boxes drawn without a GPU, custom front / spine / back / disc art, box-set carousel
- mpv / VLC player chosen for your hardware: subtitles and audio delay, 0.5×–3× speed, upscaling, HDR tone mapping,
  skip intro and credits, picture in picture, snapshots to box art
- Cast with photos, audience and personal ratings, Fix match, per-folder choice of what to scrape
- Library health (duplicates, missing episodes / artwork, offline folders), portable backups
- Streaming to browsers on your Wi-Fi, AirPlay and Chromecast (optional add-ons), Discord status
- Settings › Components shows every tool Media Vault uses and checks GitHub for new Media Vault releases
